# 🕹️ Cyber Shield: Bit Guard vs Malware Virus

**Cyber Shield** is a retro-arcade, cyberpunk-themed educational web game. Step into the digital shoes of the *Bit Guard* and defend the system's core memory from a highly dangerous *Malware Virus*. Answer real-world cyber security questions correctly to fire protective patches, deplete the virus's health, and secure the network!

## 🌟 Features

* **Educational Gameplay:** Test your knowledge on Phishing, Passwords, 2FA, Public Wi-Fi, Social Engineering, and more.
* **Multilingual Support (🌍 EN / RU / KZ):** Fully playable in English, Russian, and Kazakh. Instantly switch languages mid-game without reloading.
* **Custom Pixel Engine:** 100% vanilla JavaScript Canvas rendering. Features custom pixel-art sprites, particle explosions, and smooth animations without any external image assets.
* **Procedural Synth Audio:** Zero audio files needed! All sound effects (lasers, explosions, UI clicks, and victory themes) are synthesized in real-time using the Web Audio API.
* **Dynamic Themes:** Swap between three immersive aesthetic backgrounds:
  * 🏙️ **Neon City**
  * 🟢 **Matrix Code**
  * 🌌 **Space Deep**
* **Zero Dependencies:** Built entirely with pure HTML5, CSS3, and JavaScript.

## 🚀 How to Run

Since the game uses modern browser features (like ES6 Modules and the Web Audio API), it needs to be run on a local server rather than just opening the HTML file directly. A lightweight Python server is included for your convenience.

### Prerequisites
* Python 3.x installed on your machine.

### Quick Start
1. Clone or download this repository.
2. Open your terminal or command prompt and navigate to the project folder.
3. Run the following command:
   ```bash
   python server.py
